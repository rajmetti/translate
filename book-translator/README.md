# Book Translator

A local web app that translates EPUB and PDF books using Microsoft Foundry models (GPT, Claude, Kimi, Grok).

## Features

- Upload EPUB or PDF books
- Parse structure (spine, chapters, pages)
- Select content to translate: whole book, chapters, pages, or page range
- Translate to Hindi, Telugu, Tamil, and many other languages
- Choose from GPT, Claude, Kimi, or Grok
- Output translated EPUB or PDF
- Glossary extraction for consistent terminology

## Prerequisites

- Python 3.11 or 3.12 (3.14 is not yet supported because some dependencies lack pre-built wheels)
- Node.js 20+
- Microsoft Foundry project with API key
- (Optional) Azure CLI / Foundry Toolkit for local model discovery

## Setup

### Backend

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS/Linux
pip install -r requirements.txt
copy .env.example .env
```

Edit `.env` and add your Foundry API key:

```env
AZURE_AI_PROJECT_ENDPOINT=https://ILB-3790-Team17AIFoundry.services.ai.azure.com/api/projects/ILB-3790-Team17AIProject
AZURE_AI_API_KEY=your-key-here
```

Run the backend:

```bash
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Usage

1. Upload an EPUB or PDF.
2. Choose target language, scope, model, and output format.
3. Start translation.
4. Download the translated file when ready.

## Notes

- PDF output is generated by placing translated text on fresh A4 pages using ReportLab. Complex layouts will differ from the original.
- EPUB output preserves structure, styles, and images while replacing text nodes.
- Claude is the default translator because it follows style guides and preserves literary tone well.
- WeasyPrint and PyMuPDF were removed because they require native libraries that are tricky on Windows. PDF parsing uses pypdf and PDF generation uses ReportLab.
